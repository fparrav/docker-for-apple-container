# Tasks

Conventions for every task below:

- Python 3.9 standard library only, `from __future__ import annotations`, unittest only.
- Tests are top-level modules in `tests/` (there is no `tests/__init__.py`; `discover -s tests` puts `tests/` on `sys.path`, so helper modules such as `tests/tiers.py` and `tests/compat_matrix.py` are imported by plain name). Live modules keep the `tests/test_live_*.py` naming; this replaces the `tests/live/` layout mentioned in the design.
- Fixtures live under `tests/fixtures/compat/<letter>-<name>/`. Each fixture's first lines are `# tiers: <comma list>` and `# images: <comma list of pinned images>`.
- Matrix entry schema: `{"id", "kind", "status", "apple", "evidence", "test", "note"}`. `kind` is `command`, `option` or `compose-key`. `status` is `SUPPORTED`, `PARTIAL` or `UNSUPPORTED`. `evidence` is `unit`, `fake`, `live` or `conformance` (the highest level that has actually run). `test` is the test id (`module.Class.method`) for `live`/`conformance`, otherwise `null`. `apple` is the Apple `container` flag/command or `null`.
- Live tests are opt-in (`SHIM_TIERS=live`), name objects `shimtest-<topic>-<short uuid>`, clean up by exact name in `addCleanup`, never prune.
